# Judge 10：Originality Judge（原创性评委）评审报告

## 评审视角

我是本轮的原创性评委。我长期追踪获奖网站名录（Awwwards/FWA/CSSDA 类 SOTD）与 2024–2026 年个人站、开发者站的风格演化，我的专业工作是识别**"隐性模板味"**——那些看起来不像模板、但每一个决策都能在某类流行站点里找到出处的方案。模板味最危险形态不是"撞脸某模板站"，而是"所有决策都来自同一类流行站点的默认 taste"，作者与读者都察觉不到。

我的四个工作方法：

1. **谱系鉴定**：为每个方案指出核心语言的来源（Apple/Braun、Linear/Vercel/Raycast、独立杂志、Tufte/arXiv、瑞士海报、高端音频营销、命令面板文化……），并判定它是**引用**（知道自己借了什么，并在借来的骨架上生长出自己的系统）还是**挪用**（把某类站点的整套语法换皮搬来）。
2. **隐喻真伪检测**：对本代际的八个概念隐喻（单行本/学刊/精密仪器/抽印本/工作台/坐标纸/暗室/检索系统）做两个测试——**删除测试**（把隐喻的名字从文档中删掉，多少具体决策随之失去依据？）与**追溯测试**（能否从隐喻出发推导出 ≥5 处具体版面/交互决策？）。真概念贯穿每个决策；包装话术只在标题和 §1 出现。
3. **种子约束审计**：8 份文档中 7 份带有"种子约束落点索引"自检表，泄露了主办方给每个团队预置的必答题（如 E 的首屏 Canvas 装置与站内检索、C 的数据自证首屏、G 的单光源首屏与主题切换、H 的双模导航与自述装置均为**指派**而非自选）。原创性评分必须**只给指派槽位内的解释力与槽位之外的自选发明**，否则会把"完成命题作文"误判为"原创"。
4. **趋同审计与趋势重合度地图**：验证评委 1 指出的三组趋同（B↔D、A↔F、C↔E）及 C/G/H 主题切换撞衫，并补充我自己的发现；为每个方案标注与 2024–2026 流行语汇的重合点。

**我的价值排序逻辑（本轮核心立场）**：真正原创但执行有风险的方案 > 精致但眼熟的方案。前提有二：原创必须是能产出好决策的原创（generative originality），不是为怪而怪；眼熟方案的纪律优势可以赢得单项高分，但不应赢得概念层的第一。我的**一票否决区：originality、visual_quality**——这两个维度从严；其余维度按常规标准打分。

## 生成代际的整体趋同画像（先于逐方案的全局判断）

Round 1 的 8 份提案共享一套"代际口音"。这不是抄袭，而是同一时代 taste 的自然沉淀——但评委必须知道哪些"特色"其实是一代人的默认值：

- **字体趋同**：IBM Plex Mono 作为元数据字体 **8/8 全员采用**，且 A/C/D/G/H 五份文档用了几乎同一句辩护词——"比 JetBrains Mono 少开发者模板味/更文献/更刻字"（五个团队写了同一句 anti-JetBrains 理由，这是本代际最醒目的集体指纹）。Newsreader 4/8（A/B/D/H），Inter 系 5/8（A/C/F/G/H），Fraunces 2/8（B/G）。"grotesque 正文 + Plex Mono 元层 + 一支 display 衬线"的三声部体系是全体共享音色。
- **色彩趋同**：单 accent + 使用预算是 6/8 的自觉纪律（A 橙/B 朱砂/C 琥珀/D 朱砂/F 瑞士红/G 黄铜均有显式预算条款）——其中 **6/8 选择了暖色 accent**（橙/朱砂/琥珀/朱砂/红/黄铜），只有 E 与 H 选蓝。Dark 模式底色 **5/8 落在 #11–17 的暖近黑区间**（B #161310、D #17130F、E #12151A、G #131110、H #121110）。"暖纸 Light + 暖近黑 Dark + 一支暖 accent"是本代际的默认氛围。
- **结构趋同**：索引行/台账行取代卡片 **8/8**（基线要求）；编号章节导航 7/8；**左缘垂直索引轨 4/8**（C §6.4、E Bench Ruler、F 左缘 Rail、H 左缘锚轨——四个团队各自"发明"了同一根左边的尺子）；站内检索面板作为一等导航 3/8（C/E/H，⌘K 文化）；原位文字替换 "Copied" 且明令禁 toast：A 与 D 两家一模一样；satori/构建期生成排版 OG 图：A/D/H 三家。
- **修辞趋同**："诚实"作为品牌意识形态 **8/8**（A"诚实元数据"、B"写作者的诚实"、C"数据自证"、D"诚实是排印纪律"、E"诚实装置"、F"不掩饰不注水"、G"不编造话术"、H"诚实条款"）——这来自任务书 §3，无可指摘，但措辞与机制高度收敛。
- **Lab demo 三件套趋同**：投毒 demo **8/8 全员命题**；chunking 探索器 7/8；token 预算/检索评测 5/8。连 A（Poison Rate p + Chunk vs Recall + Evidence Trace）都加入了这套三件套。Lab 模块在本代际内部已无差异化能力，只能在工程深度（E）与教学叙事（H/D）上分高下。
- **动效宪法趋同**：`cubic-bezier(0.22,1,0.36,1)` 或近似 ease-out、120–480ms 时长分档、transform/opacity only、whileInView once、reduced-motion 三级降级——8/8 高度一致（任务书 §5 所致）。

**评委 1 的三组趋同：验证结论**

1. **B↔D（学刊 ↔ 抽印本）：确认，且是全部八组中最严重的趋同。** 铁证：两家的 Light 底色是**同一个 hex** `#FAF7F1`（B 的 `--paper` 与 D 的 `--paper` 逐字符相同）；两家把同一个颜色都命名为"朱砂"、赋予同一个修辞角色（编辑批注色/学者批注色），B `#A8341C` vs D `#A63D2A` 近乎同色；同为 Newsreader + IBM Plex Mono 双件套；同为暖近黑 dark（#161310 vs #17130F）；同有 Q 编号开放问题、同有 hairline 台账行、同有 double rule/版权页、同用"诚实"作为排印纪律的措辞。把它们并排放在浏览器里，一般访客会在 10 秒内认为是同一作者的两个栏目页。
2. **A↔F（单行本 ↔ 坐标纸）：确认，表层词汇高度重合。** radius 0、hairline 骨架、单 accent、mono 编号体系、索引行、纯文字 hero、近同的动效宪法。差异在语义层：A 的橙是"信号"（标记活物），F 的红是"构图支点"；A 隐藏网格，F 暴露网格。A 自己在 §14.2 承认了这一风险。两组的区分成立但脆弱——依赖评委细读。
3. **C↔E（仪器 ↔ 工作台）：确认，同一家族的两种姿势。** mono 元层 poetics、状态点、刻度/四角刻度母题、⌘K、诚实数据意识形态、几乎相同的 demo 三件套（投毒/分块/BM25·评测）、共享的台账行。区别是 C 展示读数（被动仪器）、E 提供工具（主动操作）。若做成中保真 mockup 并排，需要读文字才能分辨。
4. **C/G/H 主题切换撞衫：确认，但需修正责任归属。** 三家都指定 View Transitions API 的圆形 clip-path 扩散（C §5 自拨档圆心 220ms、G §7.4 Dimmer Switch 700ms、H §5 切换钮 240ms）。审计种子约束表后：G 的"主题切换 = 环境光过渡"是**主办方指派**，C 与 H 则是在无人指派的情况下各自选中了这个自 2023 年 Chrome VT demo 后已烂大街的流行交互。撞衫成立；C、H 的责任大于 G。

**我补充的趋同发现**：左缘索引轨四连（C/E/F/H，见上）；"anti-JetBrains" 五连（A/C/D/G/H）；暖 accent 六连与暖近黑 dark 五连；投毒 demo 八连；D/E 同时提出"状态是诚实的一部分"（D 的 OPEN/RESTING、E 的 exploring 状态词）；B/G 同时选用 Fraunces 高 opsz 档位做 display（B opsz144+WONK，G opsz144 禁 WONK——两个团队对同一根轴做出了相反的品味决定，这是趋同中的有趣分歧）。

## 逐方案评语

### Team A —「Monograph 单行本」

**谱系与引用判定**：核心语言来自 Apple/Braun 式极简 + 2024–26 年"安静排印型开发者主页"浪潮（Inter + Plex Mono + 单 accent + 索引行——这套组合本身已成为 anti-template 一代的默认 taste，即"反模板已经成了新模板"）。判定：**有纪律的引用**。它公开承认血缘（SF Pro 之外最接近 Apple 的免费字体、Braun/Apple 式对位），并在借来的骨架上长出自己的两套系统。

**隐喻真伪（单行本）**：**薄但诚实的真概念。** 章节骨架（sticky 左页眉栏）、mono 章节号、"永远写不完"的 caret、LAST UPDATED 元数据——删除测试下这些决策会失去部分依据。但它不冒领：没有 folio、没有 running head、没有对页思维，文档从未声称书的设计在生成网格与间距（那 12 列、160px 章距是 web 常规）。"单行本"是框架不是引擎——引擎是"类型即界面"。

**趋势重合度：高。** 单 accent 语义白名单是它对趋势的最大偏离；Inter/Newsreader/Plex 三件套、caret 闪烁、索引行 hover 词汇表都是趋势内动作；动效预算 ≤3 与"零 scroll-reveal"是逆趋势立场（2024–26 获奖站几乎全员 scroll-driven）——这是它最值钱的一条差异。

- **优点**：
  1. §4.3 的 accent 合法位置全表（"违反即 bug"）+ §7.2 动效预算表——把"克制"写成了可验收的合同，这是本代际里对"subtle"最工程化的一次定义；
  2. §3.5"双语气"修辞（sans=事实、serif italic=限定语气、全站 ≤10 处）——稀缺性管理的自觉，罕见；
  3. §5 Dark 用 variable 轴把 display 字重 500→470 补偿光渗——这是只有真正研究过排印的人才会写的细节。
- **缺点/风险**：
  1. 视觉身份高度依赖执行精度：删掉隐喻名字后，剩下的决策与大量高质量极简 portfolio 难以区分，"隐性模板味"风险为八家前列（其自评"像默认 README"准确）；
  2. 索引行 + 无表面原则在大屏与内容增长后的单调风险由 hover 微反馈独自承担，"记忆点"全押在首屏 1.8 秒仪式上；
  3. hero 的种子槽位（纯文字构图、动效预算、落版 signature）均为指派，自选发明的占比没有看起来那么大。
- **最值得偷走的想法**：accent 的"语义信号"白名单——色相不表达风格而表达状态（活物/焦点/风险），并给出全站合法位置枚举表。这套机制可直接移植到任何方案。

### Team B —「Field & Retrieval 个人学刊」

**谱系与引用判定**：核心语言来自独立杂志/报纸刊头传统 + 2023–26 年"digital print 复兴"（Fraunces 是这轮复兴的官方字体，WONK 轴是流行站点的炫技标配）。判定：**深度改编的引用**。学刊隐喻被改编到 colophon 级别（folio bar、dateline、Contents 即路由表、征稿中空态、NIGHT EDITION 戳、Lab Notes 专栏），是隐喻完成度最高的方案之一；但 display 字体的选择是趋势追逐而非必要性——去掉 Fraunces 换任何高对比衬线，方案依然成立，恰说明字体是时尚消费。

**隐喻真伪（学刊）**：**真概念，贯穿性最强之一。** 追溯测试轻松超过 5 处（Vol/№ 由真实日期推导、目录状态列、call-for-papers、版次戳、colophon、双规则线"稀缺即权威"、dateline 的"PUBLISHED WHEN THERE IS SOMETHING TO SAY"）。其自我批评 §14.6"隐喻疲劳"并主动划定四处落点，是隐喻纪律的范例。

**趋势重合度：高。** Fraunces masthead + 暖纸 + 朱砂 + mono 状态戳是当下独立工作室站的标配语汇；WONK hover 是"变量字体轴作为交互"的 awwwards 常见技；"个人站即刊物"作为 genre 有先例。它的新鲜度来自领域移植（RAG 研究者的学刊）而非语汇本身。

- **优点**：
  1. §2.1 刊头页的节制论证（唯一大动作、内页立刻安静、比例即定义）——大动作的自我约束全代际最佳；
  2. §12 空栏目以"CALL FOR PAPERS"内联进目录获得栏目存在感——空状态修辞与隐喻同构，优雅；
  3. §5 主题切换叙事为"换版次"（NIGHT EDITION 状态戳 1.6s）——隐喻最小闭环，比裸 crossfade 有叙事。
- **缺点/风险**：
  1. 与 D 的趋同是生存级风险（同一 hex 的纸、同一支朱砂、同一对字体、同一种修辞）——两者必有一家在原创性上失分，而 B 的语汇更接近流行站，暴露面更大；
  2. 刊物语汇增加解析成本（DOSSIER/Lab Note №/CALL FOR PAPERS 对招聘者是翻译层），§2.1 的 78vh 刊头延迟了第一屏信息；
  3. 四族字体 ≤260KB 的预算偏乐观，基线网格补差机制的实现成本被低估（其自己也承认）。
- **最值得偷走的想法**：空栏目作为"编辑部排期状态"进入目录（`— CALL FOR PAPERS` 斜体行）——把空状态从"缺席的辩护"变成"刊物的体例"，任何编辑制方案都该继承。

### Team C —「精密仪器 Precision Instrument」

**谱系与引用判定**：核心语言来自 Linear/Vercel/Raycast。文档自己承认："Linear 同款收敛曲线"（§7.1 ease-std 注释）、"Linear 的克制、Vercel 的 crisp、Raycast 的精确"（§1）。判定：**挪用为主，局部生长**。面板/hairline/⌘K/台账行/收敛曲线整套骨架是 Linear 语法；自选的增量是琥珀信号色、mono ≤10% 红线、SYS 数据自证、Relevance Lens 的 Jaccard-FLIP 细节。它是八家中"隐性模板味"最重的一家——把琥珀换成靛蓝，这份文档就是 Linear 官网的一次忠实转写。

**隐喻真伪（仪器）**：**半真——读数是真的，皮肤是借的。** 删除测试：删掉"仪器"，SYS 块、ILLUSTRATIVE 标注、"0 RECORDS"、ghost 槽位仍然成立（它们更直接的来源是工程 dashboard 文化和任务书的诚实条款）；追溯测试：状态灯、读数、刻度确实从仪器语义推导。但视觉决策（面板明度、hairline 透明度、缓动、⌘K 面板规格）无一来自"仪器"，全部来自 Linear。仪器是借来语法的**辩护词**，不是生成器。

**趋势重合度：极高。** Linear/Vercel/Raycast 语法 + 状态点 + ⌘K + FLIP + View Transitions 圆形扩散（自选撞衫 G/H）+ 版本号 poetics。种子审计：其两个 signature（数据自证首屏、检索式 signature interaction）均为**指派槽位**，自选发明集中在配色与纪律条款。

- **优点**：
  1. SYS 自检读数块（BUILD/RECORDS/PUBS 0 全部真实计算、`PUBS 0` 敢刻在面板上）——把诚实做成首屏读数，是"数据自证"命题的最佳解释；
  2. Relevance Lens 的约束设计（构建期预计算、DOM 顺序不变、>12 条禁用、reduced-motion 禁用）——概念炫技被驯化为可用性合格品；
  3. mono ≤10% 硬约束与"评审若看到 terminal cosplay 即执行失败"的自判——对自身方向最大陷阱的清醒。
- **缺点/风险**：
  1. 原创性天花板被自己的谱系锁死：所有记忆点（琥珀灯、⌘K、台账、面板）在 2024–26 的 dev-tool 语境里都有现成出处，"反蓝紫 AI 俗套"只是从一种流行逃向另一种流行；
  2. 首屏三联装置（读数块 + 关键词矩阵 + pipeline 图）信息密度偏高，"仪器感"与"首屏 10 秒可读"存在张力；affinity 映射是人工声明值却以透明度读数呈现，有"伪仪表"的微量嫌疑（其自己最怕的事）；
  3. Light 模式（暖纸白 + 赭金）是 Dark 的附庸，两个主题的设计投入不对称。
- **最值得偷走的想法**：`PUBS 0` 原则——空出版列表作为真实读数直接进入首屏状态块，"零"被设计成仪器的正常量程而非缺陷。

### Team D —「Offprint 抽印本」

**谱系与引用判定**：核心语言来自 Tufte-css（文档直呼"Tufte 传统"，§6.2 边注三段降级是 tufte-css 的直接工程化）+ arXiv/学术排印 + 暖纸阅读网。判定：**诚实的引用，但有依赖**。Tufte 边注与"60ch 阅读 measure"是整套借用；抽印本框架、Question Ledger 状态学、RE: 反链是自选发明。

**隐喻真伪（抽印本）**：**真概念，贯穿良好。** 论文标题区首屏、§ 编号挂边注栏、"Manuscripts in preparation."、ghost specimen 行、colophon、修订日期、"问题比结论多"的 IA——追溯测试通过。其 §14.5 对"台账诚实需要维护自觉"的自省（RESTING 三个月不更新就从诚实现场变成荒废证据）是八家中最成熟的一句话自我批评。

**趋势重合度：高。** 暖纸 + 批注红 + Newsreader 是 2024–26 阅读型站点的主流配置；边注是十年老技巧的回潮；研究节点图（SVG 手排关系图）是学术主页的常见装置（其"节点大小 ∝ 未决问题数、图上永不出现论文数"是新鲜的扭转）。与 B 的血缘重叠是最大的原创性折损。

- **优点**：
  1. Question Ledger（编号/追问/状态/最后修订）——"问题作为一级公民"是八家中最好的研究 IA 概念，`RESTING` 状态把"搁置"也纳入诚实语汇，极有人味；
  2. 四个 measure token（60/28/21/81ch）构成的行宽宪法 + "文字永不越栏"违规即 bug——排印纪律的清晰度仅次于 A；
  3. 移动端三段边注降级（漂浮注→行内嵌入注→[n] 可折叠注）是全代际最完整的"桌面装置的移动重设计"。
- **缺点/风险**：
  1. B↔D 趋同（同纸同朱砂同字体同修辞）使二者互为原创性的人质；D 的差异点（边注/地图/台账）在缩略图距离上不如 B 的刊头抢眼，先被记住的会是 B；
  2. 中屏（1000–1200px）边注系统的工程脆弱性 + 手排 SVG 地图的维护税（其自认"节点是排出来的不是算出来的"）——长期维护是八家中偏弱的一档；
  3. 视觉冲击的自我怀疑成立："论文标题区"首屏在招聘者 90 秒扫描里是安静的，记忆点押在朱砂与地图上，一旦地图被读成"又一张节点图"就失守。
- **最值得偷走的想法**：研究状态学——`OPEN / IN PROGRESS / RESTING` 三态 + `upd. 2026-10` 修订戳 + 问题↔证据的 `RE: Q2` 反链。这套语义可脱离纸面隐喻移植到任何方案，是"研究现场感"的最小实现。

### Team E —「BENCH / 工作台」

**谱系与引用判定**：核心语言来自 creative-dev 作品集 genre（"网站即作品"的宣言）+ 高级用户键盘文化（vimium 式 g-和弦、⌘K、? 帮助层——rauno/Linear 一脉）+ 实验室器物美学。判定：**综合大于挪用**。键盘体系与 palette 是文化借用，但种子审计显示这些也是**指派槽位**（键盘优先、站内检索核心导航、Canvas 首屏装置均为命题）；E 的自选发明是把这些命题编织进"诚实装置"体系的方式。

**隐喻真伪（工作台）**：**基本为真，但排在键盘文化之后。** Bench Ruler、凹槽 Lab 区、Specimen Sheet、四角刻度面板母题、Colophon 展示"台子用什么造的"——追溯测试通过；删除测试下损失中等。真正生成决策的其实是第二条原则"诚实装置"（数字现场计算、Educational prototype 铭牌、检索核可单测）。

**趋势重合度：中高。** Canvas 词场 hero 是 awwwards 常见装置，但 E 的变体（top-5 近邻连线 + PERTURBED: 12 NODES 真实读数 + 扰动→恢复=鲁棒性隐喻）把通用技挂到了研究语义上——这是全代际唯一一个"交互即研究论断"的首屏。终端式 Schematic Session 有轻微 cosplay 边缘（其自己标注了诚实版式）。C↔E 趋同压低其辨识度。

- **优点**：
  1. 首屏 P-00 的"扰动→恢复即鲁棒性"映射——研究概念被翻译成身体记忆，是八家中概念-交互咬合最紧的一处；
  2. §8 工件窗三态（Live 嵌入 / 诚实会话 / 静态图）——保证任何项目（包括五年后懒得维护的项目）都有体面展示态，是长期主义的作品集版式设计；
  3. §7 整章（和弦表、焦点管理、发现性三层、⌘K 规格）是全代际最完整的键盘 UX 工程。
- **缺点/风险**：
  1. 技术风险为八家最高：Canvas 词场 60fps、低端机降帧、sprite 图集、三台 demo 长期保活——预算表写得再好，这也是唯一需要"实现到 95 分才不塌"的方案；
  2. 静态观感是八家中最不"美"的：美被推迟到交互发生之后，10 秒扫描式评审（包括部分同行评委）会给它低分——它的赌注比 A 更极端；
  3. 与 C 的趋同 + IBM Plex 双族的朴素感，使"台面纸与钢"的第一眼身份弱于 B/D 的纸墨与 F 的海报。
- **最值得偷走的想法**：工件窗三态契约（`window: 'live' | 'session' | 'diagram'`）+ 检索核共享模块——它回答了"五年后 demos 腐烂怎么办"这一所有交互重方案共同的死穴。

### Team F —「坐标系统 Coordinate System」

**谱系与引用判定**：核心语言来自 Müller-Brockmann 以降的瑞士/国际主义 + 2017 年至今从未退潮的"Swiss/brutalist portfolio"网络亚种（暴露网格、outline 描边字、光标坐标读数、一点红）。判定：**公开的引用，转化度中等**。风格即命题（团队拿到的方向就是 Swiss），因此评分重点在其转化：档案馆系统（自动重排编号、空=表格行、FIG 编号制）是转化产物；outline 海报字与 live 坐标读数是未经转化的 catalog 动作——坐标读数 X:07 Y:03 在作品集网站上已是反复出现的旧梗（文档甚至细心地禁掉了 45.46°N 的假坐标，说明它知道这个装置的做作临界点）。

**隐喻真伪（坐标纸/档案馆）**：**真概念，系统性最强。** 删除测试：删掉"坐标"，暴露网格、档案号、R-INDEX、FIG 编号、自动重排、脊线塌缩全部失去依据——隐喻是引擎。追溯测试远超 5 处。它是"编号是数据驱动的派生值"这一思想的最佳载体。

**趋势重合度：极高（但部分是命题使然）。** 暴露网格 + 红方块 + 描边字 + 档案编号是 Swisso-web 的标准像。其原创造血点在系统层而非视觉层：导航编号由内容自动重排、空状态=表格中的一行、poster 层使用规范（何时禁止用大字）是罕见的自我约束条款。

- **优点**：
  1. §12"空 = 表格里的一行"+ 导航编号自动重排——把空状态与内容生长统一进编号系统，是八家中最彻底的数据驱动内容哲学；
  2. §3 Poster 层使用规范（仅 3 处可用、正文强调禁放大字号、用户可控文本禁入 poster 层）——对最容易被滥用的元素立了法；
  3. 移动端"12 列坐标纸塌缩为一根脊线"——用一个 1px 轴保住体系感，是概念自洽的移动重设计。
- **缺点/风险**：
  1. 视觉层几乎全部可被识别出处：描边字（约 2018 年起的 awwwards 常客）、光标坐标（作品集老梗）、红方块锚点（Müller-Brockmann 直系）——系统原创性被视觉的陈旧对冲；
  2. 与 A 的趋同（radius 0/hairline/单 accent/编号/索引行）在招聘者视角下难分；
  3. "冷、像设计工作室官网"的自评准确——第一人称温度的补救措施（Dossier 的 CURRENTLY 字段）偏弱，8 个 section 全是表格语法，节奏风险真实。
- **最值得偷走的想法**：编号系统是派生值——section 编号、档案号、FIG 号全部由内容数据推导，空模块自动消失且编号自动紧缩。这是内容生长五年不散架的结构答案。

### Team G —「暗室与晨光 The Dimmer Room」

**谱系与引用判定**：核心语言来自高端音频品牌（Devialet/Naim/B&O）+ Linear/Vercel 营销站 + 奢侈品电商。文档开篇即自认："高端音频品牌与顶级开发工具营销站共享同一套视觉语法……本方案把这套语法移植到研究者个人主页"。判定：**挪用，转化最少**。材质三级 elevation、inner hairline 高光、图片压暗 hover 恢复、vitrine 之字形舞台、H1 光泽扫过、黄铜铭牌——每一条都能在奢侈品/音频营销站找到母版。种子审计显示其两个 signature（First Light、Dimmer Switch）均为**指派槽位**，而槽位内的解释选择了最现成的答案：光呼吸 + H1 扫光（苹果产品页语法）与旋钮 + 圆形扩散（2023 后的流行交互，撞衫 C/H）。

**隐喻真伪（暗室/展厅）**：**半真，且被借来语法绑架。** 材质体系（elevation 按离光距离、Dark/Light 行为差异表 §4.3、图片压亮规范）是从"光即材料"真实推导的工程，删除测试下这部分幸存；但"博物馆/展厅"的隐喻并未生成版面——真正的展陈不会把展品排成之字形 alternating vitrine（那是营销页语法），黄铜、扫光、scrim 也来自营销而非展厅。隐喻出现在铭牌与预留展位处，记忆点却全部由借来语法承担。

**趋势重合度：极高。** 暖石墨 + 黄铜 + Fraunces 细笔画 display（与 B 共用字体、相反的轴位决定）+ mono 铭牌 + 之字形 showcase + hover 提亮图片——这是"昂贵感"的一套现成配方。其 Light 模式的 elevation 反转（更白更亮 + 暖影）与双主题行为差异矩阵是文档中真正可敬的自选工程。

- **优点**：
  1. §4.3 逐元素双主题行为差异表（hairline 方向反转、图片压亮、scrim 有无、theme-color 同步）——两套主题各自被设计的最好操作化定义；
  2. First Light 的性能预算写死（≤1.6s、compositor-only、session 一次、LCP 不延迟、降级链）——借来的动作至少被执行契约管住了；
  3. "预留展位"空态（EXHIBIT · RESERVED，hover/focus 无任何变化——"空位也是展品，不需要引诱点击"）是隐喻内最诚实的一笔。
- **缺点/风险**：
  1. 原创性为八家最低：每一个 signature 动作、每一处材质词汇、整个 layout 语言都是 catalog 货；一个研究者主页穿着音频品牌的外衣，概念与主人无血缘（RAG 研究≠音频器材，其 spec 表类比是巧辩而非必然）；
  2. Dark-first 立场（无偏好用户也默认 Dark）与图片默认压暗（信息可读性 hover 才恢复）两个决定都优先"氛围"于"任务"，与研究者访客的高效路径相悖；
  3. 之字形 vitrine 是 16:9 大图营销版式，内容为空时（当前全部 mock）最容易暴露"高级空房子"感，长期内容增长后它也是最先需要推翻的版式（其 §14.6 自己承认要加 Index 表）。
- **最值得偷走的想法**：双主题逐元素行为矩阵——把"两套主题都是被设计的"从口号变成一张逐元素验收表（含 theme-color meta、forced-colors、打印样式的行为）。任何方案的 dark/light 交付都该有这张表。

### Team H —「A Retrievable Self 可检索的人」

**谱系与引用判定**：核心语言来自命令面板文化（⌘K/query this person——Linear/Raycast 词汇）+ blur-reveal 类流行交互 + 概念驱动交互设计（site-as-corpus）。判定：**引用被概念化**。palette 本身是时代默认件，但 H 是唯一把"检索"从部件提升为**全站行为学**的方案：页面=语料、导航=查询接口、地址系统（§ 编号坐标）、Research=Query Log、Projects=证据链、空态说检索语言。种子审计：双模导航、自述装置、证据链为指派；坐标地址系统、Query Log 四行结构、Actions 化 palette、resolved 记忆为自选。

**隐喻真伪（检索系统）**：**真概念，全站级贯穿，为八家之最。** 删除测试：删掉"可检索的人"，Beam、palette 的 Actions、坐标引用（Q03 → §02）、Query Log、"no documents matched"空态全部失去依据——隐喻生成了行为而不只是皮肤。其 §14.3 的隐喻配额（检索隐喻只许出现在 4 个触点）与 §14.5 的自辩（"为什么不干脆不遮蔽？——接受挑战"）显示对隐喻过载与可及性代价的清醒。

**趋势重合度：中。** ⌘K palette（C/E/H 三连）、blur 揭示（通用技的拖柄变体）、VT 圆形扩散（自选撞衫）是趋势内动作；但钴蓝 + 暖纸的配色跳出了六家暖 accent 集群，横向证据链与 Query Log 四行结构在作品集语境里没有现成母版。

- **优点**：
  1. §9 Query Log 的四行结构（为什么问/现在/什么算进展/关联）——"什么算进展"这一栏是全代际对研究诚实性的最佳发明，比任何状态 chip 都更能定义一个研究者；
  2. §8 证据链（问题→方法→产物→链接）与 W↔Q↔Lab↔Notes 的显式关联网络——项目被定义为问题的证据，信息架构与认识论同构；
  3. §15 可用性守护清单是八家中最完整的（prefers-contrast 关闭遮蔽、遮蔽层 aria-hidden 装饰化、无 JS 全量内容、signal 永不纯色编码）——"实验必须带确定性出口"的原则被逐条落实。
- **缺点/风险**：
  1. 静态视觉身份是八家中最弱的：文档对"好看"的想象最少，钴蓝暖纸是安全的，Beam 装置是抽象的——在只读文档的评审里，它的 visual_quality 只能凭信用记账（我的从严评分反映了这一点）；
  2. 首屏装置的仪式成本：8–10 秒的揭示对 90 秒扫描者是结构性的减速带，三重防线（localStorage/skip 锚点/回访 resolved）设计正确但赌注仍在；
  3. palette 与主题切换两处撞衫（C/G/H）+ 隐喻与 C/E 的 demo 三件套重叠，使其在并排展示时需要读者抵达文字层才能看出差异。
- **最值得偷走的想法**：Query Log 四行结构——尤其"什么算进展"（what counts as progress）。任何研究型主页都应回答这个问题，它是把"研究者在思考"翻译成可验收语句的装置。

## 排名与理由

**我的排序逻辑**：概念独创性（隐喻是否生成决策、谱系转化度、与趋势及同代方案的距离）> 执行风险的定价方式（风险被写死预算与降级 = 可接受；风险被否认 = 不可接受）。精致但眼熟的方案在我的榜单上不能进入前二，无论其纪律多好。

**Top 3**：

1. **Team H（可检索的人）**——八家中唯一让"研究本身"成为全站行为学的方案：坐标地址系统、Query Log 四行、证据链反链、Actions 化 palette，隐喻真伪测试全通过且为全站级；可用性守护清单证明了"实验性"与"可用性"不必二选一。它把本代际人人都在用的部件（palette、状态词、诚实条款）编排成了一个没有现成母版的整体。扣分项（静态视觉身份最弱、首屏仪式成本）是执行风险而非概念缺陷，且风险已被逐条定价。**第一。**
2. **Team E（BENCH 工作台）**——"扰动→恢复即鲁棒性"的首屏是全代际概念-交互咬合最紧的一笔，工件窗三态契约回答了五年维护的死穴，键盘工程全代际最佳。种子审计显示其多数槽位为命题，但命题内的解释（诚实读数、检索核单测、PAUSE 常驻）是自选且原创的。扣分项：技术风险八家最高（已定价）、静态美感被推迟、与 C 的家族相似。**第二。**
3. **Team B（Field & Retrieval）**——学刊隐喻的完成度与刊头的节制论证是本代际隐喻工程的范本，空状态修辞（CALL FOR PAPERS 进入目录）与版次戳是真正长在隐喻上的发明。它输给 H/E 的原因：语汇层对流行（Fraunces/WONK、暖纸朱砂）的依赖最深，且与 D 的趋同使其原创性必须打对折计价。**第三。**

**其余排序**（一句话理由）：

4. **Team A（Monograph）**——accent 语义白名单 + 动效预算合同是真实的原创纪律，但"类型即界面"的骨架已是本代际默认 taste，隐喻最薄（诚实但不生成足够多的决策），且 signature 槽位多为命题。
5. **Team D（Offprint）**——Question Ledger 与状态学是顶级的概念贡献，Tufte 直引与 B 的孪生重叠拉低了它的独立辨识度；作为研究展示它是第一，作为"原创方案"它是第五。
6. **Team F（Coordinate System）**——编号派生与"空=表格行"是系统层的真原创，但视觉层是 catalog 动作堆叠（描边字、坐标读数），命题本身也最接近既有 genre。
7. **Team C（Precision Instrument）**——`PUBS 0` 与 Relevance Lens 值得被偷走，但 Linear 语法的整体挪用 + signature 槽位均为命题，使其成为"隐性模板味"最重的一份文档：所有决策几乎都能在 dev-tool 营销站的 canon 里按图索骥。
8. **Team G（Dimmer Room）**——工程纪律（双主题行为矩阵、性能预算）可敬，但概念与记忆点全部来自奢侈营销站的现成配方，隐喻半真且被皮肤绑架，两个 signature 均为命题且都选了最流行的解——原创性维度垫底。

**给第二轮的移植建议**（落选方案的最值钱思想）：A 的 accent 白名单与动效预算合同、B 的空栏目排期修辞、C 的 `PUBS 0` 真实读数、D 的 OPEN/IN PROGRESS/RESTING 状态学与 RE: 反链、E 的工件窗三态契约、F 的编号派生系统、G 的双主题逐元素行为矩阵、H 的 Query Log 四行——这八条合起来，就是一份比任何单一方案都更完整的"诚实的设计系统"清单。
