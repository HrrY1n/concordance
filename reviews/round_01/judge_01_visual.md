# Judge 1：Visual Design Judge 评审报告

> 评审对象：generation_01 的 Team A–H 全部八份设计提案（已完整通读，含 BRIEF.md 基线）。
> 评审日期：2026-10-05。

## 评审视角

我以获奖级网站（Awwwards / FWA）的视觉标准审视这八个方案，核心只看四件事：

1. **构图**：首屏 3 秒内有没有一个"能被截图记住"的视觉事件？记忆点是否不做作——它必须通过"截图测试"（静态截图中依然成立）和"10 秒测试"（扫描型访客也能带走一个印象）。
2. **色彩**：token 是成体系的还是拼凑的？我的判据是三条——accent 是否有书面化的使用立法（白名单/配额/语义定义）、Light 与 Dark 是否各自被独立校准过（而非反转）、非中性色的每一个出现位置能否被朗读成一句话。
3. **层级与节奏**：长页面的呼吸是否被设计（留白的分配、section 之间如何换气、5 年内容翻 10 倍后节奏是否还成立）。
4. **signature interaction 的成色**：我判定"真叙事 vs 噱头"的三条标准——(a) 它是否承载了研究论题的信息；(b) 它是否有被设计过的静态/降级形态（而不是把降级当补丁）；(c) 把它删掉后页面是否损失含义。三条全满足是叙事，两条以下是技巧展示。

**我的一票否决区**：visual_quality、originality、light_mode、dark_mode。这四维从严——9 分 = 我愿意在获奖名单里为它辩护；8.5 = 优秀但有可见短板；≤7 = 存在明显妥协或身份错位。

**零容忍清单**：炫光、玻璃拟态滥用、无意义循环动效、装饰性渐变、终端 cosplay。要特别说明：等宽大写小标签 + hairline + 状态点组成的"元数据层"本身不是罪，但当它成为一个方案唯一的视觉想法时，它就是 AI 模板味的新形态。**对"过度克制导致平庸"同样扣分**——首屏没有任何视觉事件、指望访客用耐心换取好感的方案，过不了我这一关。

**特别任务**：指认八案之间的视觉趋同（见下一节）。

## 视觉趋同指认（先说结论）

这是我的职责里最重要的一段，放在逐方案评语之前。

1. **B ↔ D 是双胞胎（最严重的趋同）**。两案的纸色是**同一个 hex**（#FAF7F1），accent 同属朱红/朱砂一族（#A8341C vs #A63D2A），同为衬线主导 + hairline 台账 + 全站 radius≈0 + 暖纸 Dark（B #161310 / D #17130F，几乎同色温）。谁抄了谁的气质？更准确的说法是：两个团队掉进了同一口"学术印刷"的井。B 靠 152px 刊名的音量与 D 拉开距离，D 靠边注系统与地图拉开距离——但把首页各自截一张内页图（index 行、空状态、colophon），不看文字几乎难以分辨归属。
2. **A ↔ F 是表兄弟**。冷中性底、hairline 骨架、编号系统、索引行语法、全局 radius 0、单一暖色 accent（橙 vs 瑞士红）。A 在 §13.1 与 §14.2 的自我辩护（"语义信号 vs 版面支点"、"网格隐去 vs 网格暴露"）在概念层面成立，但视觉骨架的共享度约五成——A 的差异化必须靠 accent 的位置纪律兑现，否则就是换色版 Swiss。
3. **C ↔ E 是方言共同体**。hairline 面板、mono 读数、状态点、刻度短线、四角标记、⌘K palette、"投毒"Lab——两案共享同一套"仪器/工作台"视觉方言。E 的独占资产是 P-00 装置与 Bench Ruler，C 的独占资产是琥珀与 Relevance Lens；除此之外两案的中性部分扫过去互为近亲。两案自己都知道（各写进 §13/§14），知道不等于解决了。
4. **主题切换圆形扩散三连**：C（§5，View Transitions 圆形 reveal，220ms）、G（§7.4 Dimmer Switch，圆形 clip-path 扩张，700ms）、H（§5，240ms 圆形 clip-path 扩散）——三个团队提交了同一个签名微交互。G 加了亮度呼吸、H 加了"重新显影"彩蛋，但核心动作是同一记。这个手法在 2023 年后已大量普及，三方都应降级为"细节"而非"signature"。
5. **全员公约数**：IBM Plex Mono 出现在**全部八案**；"mono 大写 + tracking 元数据层 + hairline"是这一代方案的共同方言。这不是抄袭，是时代空气——但它意味着差异化只能来自构图、字体主角与颜色，而恰好在这三件事上站住脚的是：A（字体即图像）、B（刊头）、E（装置）、F（海报）。G（材质）半站住。C、D、H 的静态视觉身份在方案堆里是可以被认错的。
6. **主题性撞车**：八案全部设计了"投毒语料"demo（概念趋同，视觉框架各异）。第二轮若合并方案，只能保留一个投毒 Lab，其余换题。

## 逐方案评语

### Team A — Minimalism「Monograph 单行本」

**优点**
1. §2.1 首屏是全场唯一"把字体当作唯一材料"的构图：sans→serif italic 的"双语气"切换、第三行右缩进制造的斜向张力、3×0.9em 橙色 caret——这是"克制而不平庸"的正面示范，记忆点来自排版本身而非任何装置，且完全通过截图测试。
2. §4 颜色治理是八案中最严的：accent 六处白名单（§4.3）+ 视口覆盖 <1% 的硬配额 + Light/Dark 双表全 hex 逐项标对比度 + 代码高亮也只允许一种色相。这是"体系"而非"拼凑"的定义级样本。
3. §5 Dark 模式的光学补偿——display 字重经 variable 轴 500→470、字距 +0.004em 抵消光渗、长文正文降为 ink-2 抑制 halation——是我近年设计文档里罕见的获奖级细节，证明两套主题真的被分开校准过。

**缺点/风险**
1. 十个 section 全部是"行 + hairline"的单一节奏，1216px 宽度下 Work→Open Source→Notes 连续三段行列表会摊平（§14.3 自己承认）。可执行补救：把 Lab 的"活信号"（状态点 + 读数）前移或加大权重，给中段一个密度事件，别让全站最安静的部分占据视觉中段。
2. 零图标零图形的立场让首屏除三行字外没有任何"锚定物"，执行差 5% 就会从"高级"跌到"像默认 README"（§14.1 自认）；OG/分享场景靠构建期生成图缓解，但那是站外补偿。建议给 caret 增加一个可验证的"活"证据（如 hover 显示 LAST UPDATED 日期），让克制可被确认而非被误读。
3. 与 F 的表面相似是真实风险： accent 纪律同时入镜五处合法场景（Hero + Lab 同屏）就会破功（§14.4）。需要 lint 级自查落地，否则 A 的"我不是 F"只是文档声明。

**最值得偷走的想法**：Dark 模式的可变字体光学补偿参数（wght −30、tracking +0.004em、正文降灰阶抗 halation）——所有用 variable 字体的方案都该抄这三行。

### Team B — Editorial「Field & Retrieval 学刊」

**优点**
1. §2.1 刊名 hero 是全场最强的单一视觉签名：Fraunces opsz 144 / wght 540 / WONK 1 的 152px 跨栏刊名、一个斜体 "&" 作为全版唯一的表演、3px+1px 双规则线压顶——"每期只有一处刊头"的稀缺性管理让这个大动作立得住，不做作。
2. §6.3 三级规则线语义体系（hairline / strong rule / double rule，double 全站最多两次）是排印纪律的教科书用法——权威感来自节制；§6.2 的 4px 基线网格连"破格后强制回贴"的工程代价都诚实标注了。
3. §5 主题切换被叙事成"换版次"（NIGHT EDITION 状态戳 1.6s 淡出），是三案撞车的圆形扩散之外唯一有身份的切换体验；§3.2 字阶 17 个 token 全部给到移动端值，文档完成度全场第一档。

**缺点/风险**
1. 整个首屏构图押在一个 config placeholder 上：刊名的字形长度与形态完全未知。若未来真名是 4 个字母或 14 个字母，152px 跨栏构图可能空掉或爆行。必须交付 2–3 种名字长度下的排版预案（短名配副题放大字距 / 长名降至 112px 双行），否则首屏是赌博。
2. 四个字体家族（Fraunces / Newsreader / Instrument Sans / Plex Mono）约 260KB，且 Instrument Sans 存在感最弱、职责与 Plex Mono 重叠——砍掉它让 mono 兼任 UI 层（D 的做法），同时省体积、增统一。
3. 与 D 的气质孪生（见趋同指认 #1）：纸色同 hex、朱红同族、衬线同主导。B 的独占事件（跨栏 Cover Story、WONK hover）应从首页加强，内页的 index 行与空状态需要至少一处 B 独有的排印动作，否则第二轮两案合并评审时会被当成一个方向的两个实现。

**最值得偷走的想法**：规则线的稀缺性分级——把最重的视觉元素（double rule）的用量写成硬配额（全站 ≤2 次）。"稀缺即权威"适用于任何体系。

### Team C — Modern AI「Precision Instrument 精密仪器」

**优点**
1. §7.3 Relevance Lens 是全场第二好的"真叙事"签名：hover = 一次查询，其余条目按真实 tag Jaccard 相似度 FLIP 重排 + Δ 读数淡入，sim=0 压暗（"无相关性也是读数"）——它把"检索"做成了可感知的视觉事件，且禁用条件（触屏 / reduced-motion / >12 条）全部写死，DOM 顺序不动。这是叙事，不是噱头。
2. §2.2 SYS 状态块的"数据自证"（构建时间、内容记录数、主题模式全部真实计算，`PUBS 0` 敢刻在面板上）是空内容期的最佳视觉防御——诚实本身成了构图元素。
3. 在仪器风最容易失控的两处都提前埋了刹车：§3.1 mono 占比 ≤10% 的硬约束、§6.3 刻度装饰 ≤3 组/屏。自设红线的能力是设计成熟度的标志。

**缺点/风险**
1. 原创性是 C 的软肋：hairline 面板 + mono 读数 + 状态点 + ⌘K + View Transitions 圆形扩散，正是 2024–2026 开发者工具营销站的标准方言。文档自称"Linear / Vercel / Raycast 级别的精致"——问题恰恰出在"级"这个字：它以行业最佳为基准，而不是以独特为基准。琥珀是唯一把它从模板堆里拉出来的东西，建议再极端化（例如立法"琥珀永不用于正文链接"）。
2. 首屏四件套（标题 + SYS 块 + 关键词矩阵 + pipeline 图）的构图密度全场最高，视口内有四个视觉重心，"仪器感"与"仪表盘感"一线之隔。可执行建议：砍掉关键词矩阵（信息与 §9 Research Ledger 完全重复），让首屏回到三件套并给 pipeline 图更大的呼吸。
3. Light 模式是全场第四种暖白纸（#FAFAF7 + 赭金 #9A6700），赭金做正文级 accent 的视觉张力明显弱于 Dark 的 #FFB224——Light 下这台仪器像"关了灯的"。需要给 Light 的琥珀一个图形级舞台（pipeline 读数点、focus 环之外的至少一处发光语义）做补偿。

**最值得偷走的想法**：Relevance Lens 的"hover 即查询"重排 + Δ 读数——所有行列表方案（A/F/E/D）都该偷这一手。

### Team D — Academic「Offprint 抽印本」

**优点**
1. §9.1 Question Ledger 是全场最好的研究展示设计：编号空心→实心朱砂的状态切换、OPEN / IN PROGRESS / RESTING 三态（连"搁置"都是可展示的诚实状态）、与 §9.2 地图节点的联动脉冲——学术可信度的视觉化深度无人能及。
2. §3.3 四个 measure token（60 / 28 / 21 / 81ch）把"什么允许越栏"写成了法规；§6.2 边注三段降级（浮动注→行内注→可折叠注，含无 JS 的 details 兜底）是移动端真正被重新设计的证据。
3. §4 的用色声明是全场最好的："每个非中性色的出现都必须能被朗读成一句话"——朱砂=批注/OPEN，青黛=进行中/第二语义，RESTING=ink-soft。语义色的立法范式值得全场推广。

**缺点/风险**
1. 首屏是全场最安静的：标题句 + 摘要 + 边注栏，没有任何视觉事件。§14.2 自己把这称为"好看但没劲"的赌注——作为视觉评委我确认这个风险为真："论文标题区"是概念，不是构图。可执行补救：借 F 的 ghost 手法，把当前激活问题的编号放大为朱砂 6–8% 透明度的背景级 ghost 数字，给首屏一个不吵的锚。
2. 视觉趋同（见指认 #1）：#FAF7F1 + #A63D2A + Newsreader 与 B 几乎互换。D 的差异化武器全在内页（边注、地图、台账），首屏气质与 B 难以分辨——这不是 D 抄了 B 或 B 抄了 D，而是两案都没在第一屏建立独占的视觉身份。
3. §9.2 手写 SVG 研究地图的节点坐标是"排出来的，不是算出来的"（§14.4 自认）：问题从 5 个涨到 8 个时这张图要手重排。5 年尺度下这是全案最脆的视觉资产——第二轮必须把节点布局改为数据驱动（预计算极坐标或轻量力导向），否则地图会在第三次内容更新时变成负债。

**最值得偷走的想法**：地图节点徽标只显示 "Q×n"（未决问题数）——研究可视化中永远驱逐论文数、星级等虚荣指标。

### Team E — Creative Dev「BENCH 工作台」

**优点**
1. §2.2 装置 P-00 是全场最好的首屏记忆点：词场被指针扰动→弹回 = "鲁棒性"论题本身的可视化；拖拽轨迹 = 一次检索；钉词 = 唤起全站搜索。一个签名交互同时是论点、是玩具、是导航——这是"视觉叙事而非噱头"的定义级实现，且它通过截图测试（静态词场 + 读数也成立）。
2. §2.2 性能预算表是八案中最严肃的性能设计：帧预算按 deviceMemory 缩减节点、词条 sprite 预渲染、邻接构建期一次算清、双停机条件、连续掉帧自动降级；`renderStatic()` 保证 reduced-motion 静态帧与动态帧同源——降级态也是被设计的，不是补丁。
3. §4 制图蓝 + 铅封红的二元语义（蓝=图纸/交互，红=投毒/警示且只出现在 LAB-01）给冷灰钢面注入了叙事色；§6 工件窗四角刻度母题统一全站而克制。Lab 凹槽区作为"页面唯一的底色变化"是漂亮的空间修辞。

**缺点/风险**
1. 视觉方言与 C 高度共享（见指认 #3）：hairline 面板、mono 读数、状态点、⌘K、刻度线——E 的独占资产只有那台装置和那把钢尺。建议把"凹槽台面"从 Lab 专属扩大为一个更强的空间层级语言（例如 Work 的工件窗也落在浅一档的凹面上），把方言差异拉开。
2. §8 版式一的"终端式会话打字预览"（12ms/字符逐字打字）踩在我的廉价手法警戒线上：即便内容诚实标注，打字机动效在 2026 年的获奖语境里已是陈词滥调。建议改为整块淡入 + 常驻光标，删掉逐字过程——信息无损，品味回血。
3. Plex Sans 的气质撑不起 88px 的 display-1 主张行；hero 的视觉重心几乎全押在装置上，而装置在低端安卓会降级为 90 节点 + 隐藏连线——届时首屏会从"工作台"退化为"白板 + 一行字"。必须给主张行一个排版级备胎（A 式灰度对比或 B 式衬线切换），作为装置降级时的第二视觉锚。

**最值得偷走的想法**："扰动→恢复"作为首屏论题的可视化——让 hero 的交互直接演示研究主张本身，而不是演示作者的技术。

### Team F — Swiss「Coordinate System 坐标系统」

**优点**
1. FIG.00 构成主义首屏的视觉冲击力全场第二：三行阶梯右移 + GENERATION 的 outline 描边字 + 十字准星与红方块支点 + live 坐标读数——"坐标纸"概念 3 秒可读；§3 的 Poster 层使用规范（仅 3 处、禁入正文、禁动态内容）把这个音量管住了。
2. §12 空状态 = "表格中的一行"（P— 行 + `// auto-renders` 注脚）+ 编号自动重排，是八案中对"空"最优雅的登记语法——空不是留白，是数据。
3. §11 移动端"脊线"方案（12 列坐标纸塌缩为 1 根轴 + 红 tick 随滚动）是真正的移动端重设计：体系感完整迁移到单列，且成本极低。

**缺点/风险**
1. 原创性是八案最低：Swiss 复兴 + 描边大字 + 红色点睛 + 暴露网格，是 2018–2025 作品集圈的高频套路。live 坐标读数可爱，但它"教访客读网格"的功能 10 秒就完成了，之后沦为背景噪音——本质仍是装饰。F 的"档案"内核被它的"海报"皮肤拖着走，第二轮需要决定到底要哪个。
2. Dark 模式是全场最弱的一档（我的一票否决区内失分）：#121212 中性暖灰 + 提亮红，概念（"夜晚网格浮起"）好，但 token 表在 `--code-bg` 之外**没有任何代码语法色**——对一个开发者站点这是硬缺口；描边字在暗底的对比度问题完全未讨论；缺少 A/C/G 那种逐元素双主题校准表。
3. §8 hover 五联反馈（行底色 + 编号变红 + 左缘红线生长 + 标题右移 8px + 加号变红）在 72px 行高里同时发生五件事，逼近其自设的克制红线。建议减为三件（底色、红线、编号），把"确定感"留给更少但更准的信号。

**最值得偷走的想法**："空状态 = 表格里的一行"——空内容以登记行的方式在场，配 auto-renders 注脚，比任何"敬请期待"体面。

### Team G — Dark Premium「The Dimmer Room 暗室与晨光」

**优点**
1. §4.1 Dark 是全场最好的暗色模式：暖石墨 #131110 + 黄铜 #C2A165、elevation 三档提亮 + inner-highlight 顶光替代阴影、图片压暗 0.86 + hover"射灯移过来"（§4.4）、§4.5 双主题图表 token 各成一套——材质语言完整到可以直接开工。
2. §4.2 Light 的 elevation 方向反转（层级越高越白 + 暖影替代高光）证明两套主题被真正分开设计；§4.3"两套主题中行为不同的元素"逐元素对照表（scrim 有无、hairline 方向、图片处理、theme-color 同步）是八案唯一，应成为所有方案的交付模板。
3. §9.3 实验即"音响器材规格表"（mono spec 表 + readout）与 §10 仪器机架，是"研究感"与"奢侈品感"少有的成功嫁接；Publications 空状态"预留展位"（EXHIBIT · RESERVED，hover 无任何变化）的分寸感很好。

**缺点/风险**
1. 两个 signature 都踩在我的一票否决区边缘：H1 光泽扫过（plus-lighter 斜向高光条）是 2012 年消费电子产品站的老手法，"只扫一次"改变不了它属于廉价 gloss 家族的事实——建议整段删除，保留灯光呼吸即可，1.6s 的预算反而更干净；Dimmer Switch 的圆形扩散与 C/H 撞衫（见指认 #4），应降级为细节。
2. Vitrine 展柜版式的成立前提是"有值得打光的图"，而本站未来三年的现实是截图稀缺、内容空旷。21:9 个展位 + scrim 在无图降级态（inset 底 + mono 代号）会暴露整个体系对图像的依赖——§14.6 的"Index 表 + 精选展柜"双层结构应该是**默认态**，而不是五年后的补救。
3. 身份错位风险："暗室 + 黄铜 + 高对比衬线"的奢侈基调，看起来像一个已经成功的品牌的产品官网，而不是一个研究生、零论文、正在求职的人的长期居所。黄铜的克制全靠自觉（§14.2 自认），没有 A/C 那种书面化白名单——需要在交付前把"brass 允许出现的四处"写成 lint 规则。

**最值得偷走的想法**：§4.3 双主题逐元素行为表——一张表管两套主题（图片压暗系数、hairline 方向、elevation 方向、scrim、theme-color），让"Dark 不是反转"从口号变成验收清单。

### Team H — Experimental「A Retrievable Self 可检索的人」

**优点**
1. §4 的双语义色系是全场最有思想的颜色体系：accent（钴蓝）=可信/可交互，signal（警戒橙）=投毒/攻击，且立法"signal 永不单独出现、必配 ▲ 或文字标签"——颜色在教访客读研究，这超出了"好看"的范畴，是色彩作为内容。
2. §8 证据链把项目做成"问题→方法→产物→链接"的横向因果轴：display-2 问题句 ≤24ch 强制口语化（给招聘者的），mono 方法列表（给研究者的）——同一条链上两种受众分层，是作品集展示的原创格式，且 600ms 单向绘制后永久静态。
3. §15 可用性守护清单（键盘全图、reduced-motion 全量降级表、无 JS 可达、prefers-contrast: more 关闭遮蔽）是八案中最完整的一章——它保证了这个实验性方案在残缺环境下不塌，这在"Experimental"标题下尤其可贵。

**缺点/风险**
1. 首屏 sealed 态是全场最弱的"第一眼"：四行 `blur(5px) + opacity .35` 的摘要意味着访客看到的第一个屏幕有一半内容是糊的。在视觉上这叫"未完成感"，不叫"悬念"——即使 DOM 完整、可跳过、可回放，视网膜的第一印象只有一个版本。可执行补救：遮蔽改为视觉上成立的形态（ink-faint 实色摘要，或 mono 编号 + 细线的"未检索"态），保留隐喻，扔掉糊。
2. resolved 后"四行折叠为索引条、页面高度回收 40%"会造成首屏在访客交互 10 秒后整体回流一次——这是 CLS 级的视觉事故。折叠必须被设计成有意的版面事件（如新内容从底部以 200ms 推入并锚定），而不是高度跳变。
3. 静态视觉身份（Newsreader + Inter + Plex Mono、暖纸、hairline 台账）在八案中无独占性：把 H 认出来的只有装置和钴蓝。而回访者 100% 会跳过装置（resolved 记忆）——届时 H 的首页气质滑向 B/D 的近亲。resolved 态需要一个专属构图而不是"折叠收场"。

**最值得偷走的想法**：accent / signal 双语义色系——让配色系统本身承载研究语义（可信 vs 被攻击），并立法"signal 状态永不以纯色编码"。

## 排名与理由

**Top 3：**

1. **Team A（Monograph）**。全场唯一"零赘肉"的视觉体系：字体即图像的首屏、accent 白名单与 <1% 配额、双主题各自独立校准（Dark 光学补偿是全场最获奖级的单一细节）、动效预算表把克制写成了可验收条款。它把"没有设计动作"作为设计动作，且通过了截图测试与 10 秒测试。风险（单调、执行精度）全部被自我指认并给出缓解路径——一份知道自己在赌什么、并把赌注写成条款的视觉方案。
2. **Team E（BENCH）**。首屏记忆点全场最强，且记忆点即论点（P-00 扰动→恢复就是鲁棒性）；性能预算与同源静态降级达到了可直接进实现的密度；红蓝双语义给工作台注入叙事。失分在与 C 的方言共享与打字机预览的品味失误——都是可修的局部。
3. **Team B（Field & Retrieval）**。单一视觉签名最响亮（152px 刊名 + 双规则线），排印纪律最纯正（规则线稀缺性分级、4px 基线 + 破格补差）。失分在首屏押注未知的名字、四字族载荷、与 D 的气质孪生——前两者有明确的修复动作，第三个需要第二轮在内页制造 B 独占的视觉事件。

**落选说明**：

- **G**：拥有全场最好的 Dark 模式与唯一的双主题行为表，但两个 signature 一个是陈词滥调（扫光）、一个是撞衫（圆形扩散），vitrine 对空内容期不友好——它是"最好的暗色"，不是"最好的视觉方案"。
- **F**：首屏冲击力足够，但原创性是八案最低（Swiss 复兴是红海），Dark 模式与代码 token 缺口在我的否决区直接失分。
- **D**：研究展示（Question Ledger + Map）全场第一，但首屏零视觉事件 + 与 B 的孪生气质，visual_quality 过不了我的严苛线。修复首屏锚点后，它有决赛实力。
- **C**：Relevance Lens 值得任何一轮决赛，但整体视觉是"熟悉的陌生人"——Linear 方言 + 第四种暖白纸，originality 拉不回来。
- **H**：概念最聪明、颜色语义最深、可用性章节最完整，但"第一屏一半是糊的"在视觉评委这里近乎致命。修好 sealed 态的视觉形态与 resolved 回流，它有能力进任何一轮。
