## A. 本轮目标

本轮改版以「**中文优先、作品更强、层次更丰、学术气质长存**」为核心纲领，旨在彻底解决上一版本中“全站偏英文导致阅读门槛高”、“视觉过于克制素淡以致作品感不强”、“首页更像研究专题而非主理人个人主页”的三大痛点。

1. **中文优先（Chinese-first）**：主标题、核心叙事、全站导航、命令面板、实验仪器与空态提示全面中文优先呈现，必要英文技术术语作为精准辅标。
2. **强化个人主理身份（Personal Ownership）**：首屏明确树立 `@HrrY1n` 个人主页与研究档案属性，清晰传达「计算机科学硕士研究生 · RAG 鲁棒性/投毒 · 独立软件工程与设计」的复合背景。
3. **重度增强作品视觉呈现（Visual Enrichment）**：彻底破除纯文字列表与卡片堆叠，在首页与作品页打造杂志式大图版（Plate Layout），真实界面截图提前至首屏视口下方，配以详尽图注、技术标签与完整案例入口。
4. **恪守设计资产与真实性纪律**：完整保留暖纸/阅读室双主题、Inter+Newsreader+Mono 排版体系、§00–§07 章节坐标与纯前端计算机制；不编造任何个人隐私与未经证实的经历。

## F. 已知限制与说明

1. **中英文技术术语并存**：为了保持对技术同行的专业性，部分核心名词（如 Local-first、Web Audio API、IndexedDB、BM25）保留了英文技术原词，这是刻意为之的设计决策。
2. **静态 head 输出边界**：深链静态输出为各路由生成了包含完整 SEO / 社交分享元数据的独立 HTML 入口，页面正文依然由前端客户端激活渲染（非完整 SSR，但满足静态部署与搜索引擎索引需求）。
3. **SoundIsle 线上体验**：soundisle 开源代码未部署在线 Demo，案例页严格遵循真实性不放虚假 Demo 链接。
4. **跨平台设备字体说明**：CSS 声明了覆盖 Windows（微软雅黑）、macOS（苹方 / 宋体）与 Android/Linux（思源黑体/宋体）的完整中文字体回退链。本地自动化测试基于 Windows 11 环境 Chromium 完成；macOS 与移动端真实实体机硬件渲染效果在当前 Windows 宿主上未直接真机观测，已如实注明。
